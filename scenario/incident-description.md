# Incident Description

Date: [Today’s date]

A user reported a suspicious email claiming to be from a trusted organization. The email contains a link requesting the user to verify account information.

The user did not click the link and forwarded the message to the Security Operations Center (SOC) for analysis.

SOC Objective:
- Determine if the email is malicious
- Identify indicators of compromise (IOCs)
- Assess risk
- Recommend containment actions
